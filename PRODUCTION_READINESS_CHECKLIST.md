## Allowed Status Definitions
- ✅ **PASS**: Fully tested and working with verified code and behavioral evidence.
- ❌ **FAIL**: Tested and verified not working as intended.
- ⚠️ **PARTIAL**: Works, but contains limitations, edge-case leaks, or partial coverage.
- ⛔ **BLOCKED**: Cannot test due to missing external hardware/production credentials.
- 🔍 **NOT IMPLEMENTED**: UI or code references feature, but no backend/frontend logic exists.
- 🟡 **NEEDS VERIFICATION**: Requires live physical hardware (e.g., biometric scanner) or production SMS gateway.
